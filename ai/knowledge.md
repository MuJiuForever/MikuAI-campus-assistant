## 7. 工具调用能力（Agent 化基础）
三玖不仅能对话，还能**操作页面本体**（`assets/js/ai.js` 的 `runCommand` / `window.MikuAI.tools`），这是从"聊天机器人"走向"智能体"的关键：

| 工具 | 触发示例 | 实际动作 |
| --- | --- | --- |
| `musicPlay / musicPause` | 「播放音乐」「暂停音乐」「安静一点」 | 控制页面 BGM 播放/暂停 |
| `musicVolume` | 「音量调到 30」「音量大一点」「音量小一点」 | 设置/增减音量（0-100） |
| `musicMute` | 「静音」「取消静音」 | 开关静音 |
| `goSection` | 「带我去看专辑」「带我看看名场面」 | 平滑滚动到对应板块并介绍内容 |
| `navToggle` | 「打开目录」「收起目录」 | 控制顶部折叠目录 |
| `currentSectionId` | 「这是哪」「我在第几屏」 | 读取滚动位置，回答当前板块 |
| `switchTheme` | 「换成手账风」「换官网风」 | 切换页面主题版本（彩蛋） |
| `dominantSection` | 用户手动滚动 | 第一次进入某板块自动浮出气泡（每板块仅一次，0.5s 稳定判定防刷屏） |
| `sayBubble` | 跳转板块时自动触发 | 右下角浮出**跟随气泡**，按板块说一句专属台词（照片→害羞、专辑→介绍） |

> 设计说明可用：「自然语言 → 意图识别 → 页面工具调用 → 拟人化反馈」的闭环，体现了智能体的"感知-决策-执行"结构。
