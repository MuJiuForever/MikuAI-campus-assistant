# MikuAI 多学校知识库

## 当前状态

- 已接入：重庆大学 / CQU-openlib
- 性质：社区开源资源，非学校官方资料
- 已导入：551 篇有效正文、3498 个知识块、4369 条课程与资源元数据
- 前端：不显示知识库入口
- 服务端：自动检索并在需要时注入 DeepSeek 上下文

## 为什么不是微调

视频/网页资源站会持续更新，直接“训练进模型”会导致：

- 更新困难，下一次资料变更又要重训；
- 来源无法追溯；
- 容易把一段时间的旧政策当成永久事实。

当前采用 RAG：

```text
用户问题
  → 意图与关键词检索
  → 学校知识块 / 课程目录
  → 注入三玖人格 Prompt
  → 大模型总结回答
  → 保留来源链接
```

## 检索范围

- 校园学习、竞赛、转专业、培养方案、入学、防诈骗、校车、社团、技巧、校园生活等。
- 4369 条课程目录支持按课程名、课程代码查询。
- 课程页只有“暂无数据”时，只保留课程目录，不把占位文本当正文。

## 后续其他学校

新增学校不要求改页面，只需要：

1. 在 `data/knowledge/schools/<school-id>/source.json` 填写站点信息。
2. 运行导入器。
3. 重启服务端。

服务端会遍历 `data/knowledge/schools/*/`，自动加载所有学校。未来开发成独立 Agent 时，这份数据可以直接复用。
## 验收

运行 `node tools/audit-school-knowledge.js`。

最近报告保存在 `data/audit-school-knowledge-latest.txt`。
