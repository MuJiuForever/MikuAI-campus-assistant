# 中野三玖 · 应援展示页

一个为《五等分的新娘》角色 **中野三玖（Nakano Miku）** 制作的单页粉丝展示网站。

> 三玖天下第一！💙

## 预览

直接双击打开 `index.html` 即可（纯静态页面，无任何依赖，无需联网），
或在本目录启动一个本地静态服务器后访问：

```bash
# 方式一：Node（本仓库自带 server.js）
node server.js
# 浏览器打开 http://localhost:8123

# 方式二：Python
python -m http.server 8123 -d .
```

## 目录结构

```
中野三玖展示页面/
├── index.html          # 页面主体
├── assets/
│   ├── css/style.css   # 全部样式（暗夜蓝主题）
│   ├── js/main.js      # 星空、滚动动效、小知识等交互
│   ├── img/
│       ├── miku.svg    # 粉丝绘制的风格化立绘（矢量）
│       └── favicon.svg
│   └── music/          # 背景音乐（bgm.mp3 主音源 + bgm.ogg 兜底）
```

## 技术要点

- 纯 HTML + CSS + 原生 JS，无框架、无外部资源，离线可用
- Canvas 星空 + 流星、CSS 极光与飘落花瓣背景
- 入场滚动动画（含视口内兜底显示）、导航滚动高亮、移动端菜单
- 背景音乐控件：耳机风格徽章 + 播放/暂停 + 音量滑杆 + 静音，音量自动记忆
- 响应式布局，适配桌面 / 平板 / 手机
